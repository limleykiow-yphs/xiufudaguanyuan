《梦回大观园》学生版与教师设置

学生版：
- 打开后直接显示地图。
- 地图使用 Canvas 绘制点击区。
- 完成前一关后自动开放下一关。
- 每关从题库中随机抽5题。
- 自动保存金币、正确题数和关卡进度。
- 支持背景音乐、点击音、答对音和答错音。

教师版：
- 可直接拖动地图上的15个编号卡点。
- 可输入精确的 X、Y 百分比坐标。
- 可修改地点名称、代表人物、图标和修复任务。
- 可修改题目、4个选项、正确答案、难度和解析。
- 可新增或删除题目。
- 可导出 config.js 或 JSON。
- 可导入之前导出的 JSON 继续编辑。

让教师设置应用到学生版：
1. 在教师版完成调整。
2. 点击“导出 config.js”。
3. 用新下载的 config.js 替换游戏文件夹内原有的 config.js。
4. 重新打开学生版.html。

请保持以下文件和文件夹在一起：
学生版.html
教师版.html
config.js
style.css
images/
audio/


新增游戏统计：
- 答对一题：基础10分、20金币。
- 连续答对3题起可获得额外连击奖励。
- 首次完成关卡：额外50分、100金币。
- 游戏画面显示得分、金币、正确、错误、连击和完成关卡数。
- 每关完成后显示本关结算和星级。
- 四个选项会在每次出题时自动随机排列，正确答案不再固定为A。


人物解锁功能：
- 学生版地图不直接显示代表人物。
- 默认在完成该景点后，才会揭晓代表人物并加入人物图鉴。
- 答题开始前只显示人物线索，不直接给出答案。
- 教师版可为每个地点选择：
  1. 始终隐藏
  2. 通关后显示
  3. 立即显示
- 教师版也可修改人物线索，避免线索过于明显或直接泄露答案。


正式闯关规则：
- 已完成关卡再次点击时，会询问是否进入练习模式。
- 练习模式默认不增加得分、金币、正确题数、错误题数或连击。
- 完成正式关卡后，可直接点击“进入下一关”。
- 首次通关奖励只会发放一次，无法重复刷取。
- 教师版可设置：
  · 是否允许重复练习
  · 练习是否给予奖励
  · 是否显示“进入下一关”
  · 每关抽题数
  · 每题得分与金币
  · 首次通关额外奖励


动态修复地图：
- 0～3关：地图略显暗淡，处于待修复状态。
- 4～7关：地图逐渐变亮，开始出现修复光效。
- 8～12关：水波、灯笼和花木效果更加明显。
- 13～15关：进入“梦回大观园”阶段。
- 每完成一个地点，该地点会出现金色光圈、花朵和灯笼效果。
- 完成15关后会播放花瓣和星光庆祝动画。
- 学生版可点击“查看修复前”和“查看当前成果”进行比较。
- 教师版可控制地图变亮、水波、花朵光效和最终庆祝动画。


Excel题库：
- “梦回大观园_题库管理.xlsx”包含全部现有题目。
- 题库工作表可修改题目、选项、答案、难度和解析。
- 关卡统计工作表会自动统计每个景点的题量与难度分布。
- 游戏设置工作表保存奖励与动画参数。
- 当前游戏仍读取 config.js；Excel作为题库主档和后续导入系统的标准格式。


教师版 Excel 一键导入：
1. 打开“教师版.html”。
2. 点击“导入 Excel”。
3. 选择“梦回大观园_题库管理.xlsx”。
4. 系统会自动检查景点、选项、答案字母、难度与重复题。
5. 导入成功后，点击“导出 config.js”。
6. 用新下载的 config.js 替换游戏文件夹内原有文件。

Release 2.5 Windows桌面保存版：

一、推荐打开方式
1. 完整解压整个游戏资料夹。
2. 双击“启动教师后台.bat”。
3. 系统会打开教师后台浏览器页面。
4. 修改后点击“保存全部资料”。

二、保存与备份
- 教师后台会直接覆盖游戏资料夹中的 config.js。
- 覆盖前会自动把旧 config.js 复制到 Backup 文件夹。
- 备份名称含日期、时间与原因。
- 教师版“备份记录”可查看、恢复和删除 Backup 文件夹中的备份。
- 恢复备份前会先建立一份安全备份。

三、技术说明
- 桌面保存服务使用 Windows 内置 PowerShell，不需要安装 Python、Node.js 或其他软件。
- 服务仅监听本机 127.0.0.1，不会开放到外部网络。
- 关闭 PowerShell 黑色窗口后，桌面保存服务会停止。
- 普通双击教师版.html仍可使用，但不能自动写入 Backup 文件夹。

四、安全提醒
- 请保持“启动教师后台.ps1”和“启动教师后台.bat”在游戏资料夹根目录。
- Windows首次执行时可能显示安全提示，请选择允许在本机运行。

V1.1 统一资料同步版：

一、推荐使用方法
1. 完整解压资料夹。
2. 双击“启动教师后台.bat”。
3. 在教师后台修改题目、景点提示、地图、音乐或外观。
4. 点击“保存并同步学生版”。
5. 返回学生版并重新载入页面。

二、统一资料机制
- 教师后台会将完整 config 资料保存到浏览器的：
  dreamGardenSharedConfigV1
- 学生版启动时会优先读取这份最新资料。
- 没有浏览器同步资料时，才读取资料夹中的 config.js。
- 教师版每次修改后约0.5秒自动保存到浏览器。
- 学生版已打开时，会收到更新提示，可立即重新载入。

三、跨电脑发布
- 浏览器同步资料只适用于同一台电脑和同一浏览器。
- 要复制到其他电脑，请继续使用“写入 config.js”或“导出 config.js”。
